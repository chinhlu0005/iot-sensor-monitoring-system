
# Báo cáo tiến độ - Tuần 1

## Đề tài
Hệ thống giám sát cảm biến IoT

## Môn học
Phát triển ứng dụng phân tán

## 1. Công việc đã thực hiện

- Khởi tạo dự án trên Visual Studio Code.
- Kiểm tra môi trường phát triển.
- Khởi tạo Git Repository với nhánh main.
- Cấu hình thông tin Git.
- Xây dựng cấu trúc thư mục ban đầu.
- Tạo file README.md giới thiệu dự án.
- Tạo file .gitignore quản lý file không cần thiết.

## 2. Công nghệ dự kiến

- Backend: ASP.NET Core Web API
- Frontend: React
- Database: PostgreSQL
- IoT Simulator: Python
- Communication: MQTT
- Real-time: SignalR
- Deployment: Docker Compose

## 3. Kết quả

Đã hoàn thành việc chuẩn bị môi trường
và cấu trúc dự án ban đầu.

## 4. Kế hoạch tuần 2

- Thiết kế kiến trúc hệ thống phân tán.
- Thiết kế cơ sở dữ liệu.
- Xác định định dạng thông điệp MQTT.
- Chuẩn bị cấu hình Docker Compose.
